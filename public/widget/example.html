AI Support Chat Widget

This page demonstrates how to integrate the AI Support chat widget into your website. The widget appears in the bottom-right corner of the page.

Basic Installation

Add this script tag to your HTML, just before the closing </body> tag:

<script src="https://your-domain.com/widget/chat-widget.js" data-company-id="your-company-id" data-api-url="https://your-api.com/api/v1" ></script>

Configuration Options

Customize the widget by adding data attributes to the script tag:

Attribute Description Default Required
data-company-id Your unique company identifier - Yes
data-api-url API endpoint URL http://localhost:3000/api/v1 No
data-position Widget position: bottom-right, bottom-left, top-right, top-left bottom-right No
data-primary-color Primary color (hex code) #0891b2 No
data-title Widget title Support Chat No
data-welcome-message Initial greeting message Hi! How can we help you today? No
data-placeholder Input placeholder text Type your message... No
data-category-id Knowledge base category ID null No
data-auto-open Auto-open widget on page load false No

Advanced Example

Full configuration with custom styling:

<script src="https://your-domain.com/widget/chat-widget.js" data-company-id="comp_123abc" data-api-url="https://api.yourdomain.com/api/v1" data-position="bottom-right" data-primary-color="#7c3aed" data-title="Help Center" data-welcome-message="Welcome! How can I assist you?" data-placeholder="Ask us anything..." data-category-id="cat_support" data-auto-open="false" ></script>

Note: The widget stores conversation data in localStorage to maintain conversation continuity across page reloads. Ensure your company_id is correct to properly route conversations.

Features

  • Responsive design (mobile and desktop)
  • Conversation persistence across page reloads
  • Real-time AI responses
  • User information collection
  • Minimize/maximize functionality
  • Typing indicators
  • Customizable colors and position
  • Auto-open capability
